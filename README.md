# 尚香书院（Discuz! X3.5 小说论坛客户端）

基于 Android WebView 的 Discuz! X3.5 小说论坛壳应用。当前版本 **v1.8.4**。

## 功能

- **浏览**：电脑版网页、下拉刷新、返回键退网页历史、站外链接走系统浏览器、登录态持久化
- **版面列表返回不丢页**：列表页点开的帖子 / 标签 / 分类在新界面打开，返回时列表的多页内容与滚动位置原样保留（结构化方案，不依赖任何 JS 还原脚本）
- **附件**：付费附件自动购买 + 下载，普通附件点一下直接下、无弹窗；保留真实后缀，自动去站点标记、修复乱码文件名
- **下载管理**：搜索过滤、多选批量处理，可只移除记录或连本地文件一起删
- **内置 TXT 阅读器**：连续滚动、章节目录、字号行距、背景主题、阅读位置记忆
- **自动签到**：进入论坛自动完成，自动计算验证题
- **清爽浏览**：屏蔽弹窗广告（popadv 插件 / 广告联盟 / 自动弹窗）与外链推广分区；帖子正文图片按站点原生方式显示
- **自定义脚本**：设置页可粘贴 JS 或**导入本地脚本文件**，网页加载后在内置脚本之后执行
- **下载重命名**：一律用**附件原来的名字**（去掉 `[sxsy.org]` / `soushu2025.com` / `@` 等站点标记），不用帖子标题顶替
- **大文件下载**：浏览器通道改为流式落盘，10MB 以上 TXT 不再因内存峰值失败
- **外链分区自动识别**：按 Discuz 官方「链接到外部地址」文案判定 redirect 型推广分区，站点新增外链分区无需升级即可自动隐藏（导航层同步拦截）
- **安全**：SSL 证书白名单校验、关闭本地文件访问、JS 接口域名白名单

## 快速使用

1. 安装后打开，首次在设置页填写论坛网址（默认预填 `https://sxsy45.com`）
2. 在网页内登录论坛账号
3. 进帖子点附件 → 自动购买并下载；右上角菜单「下载文件」里用内置阅读器打开

## 技术栈

Kotlin ｜ minSdk 21（Android 5.0）｜ targetSdk 34 ｜ JDK 17 + Gradle 8.7 + AGP 8.4 ｜ AndroidX + 系统 WebView

## 编译

```bash
gradlew assembleDebug      # 或 assembleRelease（需 keystore.properties）
```

`keystore.properties`（指向 `sxsy.keystore`）已通过 `.gitignore` 排除，请自行备份 —— 密钥丢失后新版本将无法覆盖安装。

## 更新日志

### v1.8.4

- **下载通道定优先级**：点击附件（「白嫖下载」）改由系统下载监听接管，即时提示「开始下载：<文件名>」并显示系统级进度；拦截网不再抢先对直链做整份静默探测（十几 MB 要几十秒且期间无任何反馈）。用户点过的地址 10 秒内拦截网一律放行；直链另加 3 秒兜底——下载监听未接管时自行发起，避免个别模板点了没反应
- **通道去重**：同一地址 60 秒内只允许落盘一次，彻底消除「同一文件被下载两遍」；占位在下载失败时释放，不影响重试
- **文件名加固**：URL / 路径冒充的文件名一律拒收（直链下载按钮的 `title` 就是完整 URL，且以 `.txt` 结尾，能骗过「带扩展名才算文件名」的判据，曾导致存成 `https data_attachment_..._xxx.txt`）
- **自动签到修复**：`#k_misign_topb` 自身就是那个 `<a>`（内部只有一个 `<img>`），旧逻辑却在其内部找 `a[href*="qiandao"]`，导致首页签到入口永远识别不到；改为支持「元素自身是 `<a>`」并新增 `a[href*="id=k_misign"]` 等兜底。同时不再「点完就乐观标记当天已签到」——改为以 DOM 的「已签」状态为准，避免一次失败锁死一整天
- **卡顿优化**：清理三处常驻定时器中的全文档查询 —— 附件名上报脚本（300ms×20s 无条件扫描、且 `nameOf()` 未先去重）、fwin 广告清理（250ms 无条件 `querySelectorAll('[id^="fwin_"]')`）、购买浮层轮询（400ms 无条件全文档查询，且在「有付费附件但未自动购买」的帖子上永不停止）

### v1.8.2
